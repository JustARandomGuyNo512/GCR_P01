# GCR Forge 1.20.1 — нововведення для офіційної публікації

**Основа:** `forge-1.20.1-port` (`c777cfa4667190514ec085e4d03e243195f7451a`)  
**Джерело останніх змін:** `gcr-aftermatch-1.20.1` (`9f7e63d0f4acffad53faf4ebb745932eef48f850`)

**Статус:** гілка компілюється окремим GitHub Actions workflow; повне ігрове тестування релізу ще потрібне. Гілка призначена для подальшої офіційної розробки та публікації після перевірок.

## Реалізовано

- Незалежні фізичні магазини, набої та патронник; чотири калібри: 5,56×45, 5,45×39, 6,8×51 Fury, 7,62×39.
- Текстури 32×32 для всіх чотирьох калібрів замість залізного самородка, включно зі старими ID патронів.
- Подвійне R виймає магазин; повторне подвійне R виймає патрон із патронника в інвентар (на землю лише якщо інвентар заповнений).
- Коротке утримання R із відпусканням — швидке перезаряджання; довге — радіальне меню. Пріоритет останнього вручну вибраного типу магазина зберігається для конкретної зброї.
- Адаптивні пелюстки радіального меню, групування магазинів із однаковим вмістом (`×N`), сортування, підсвічування центральної зони скасування. R підтверджує вибір або скасовує в центрі; ESC не скасовує.
- Під час відкритого меню працюють WASD, стрибок, присідання та спринт, але камера мишкою не повертається.
- Заряджений магазин позначається `(+)`; порожній — без позначки. Тултіп вказує сумісну зброю та підказки «Затисніть R для заряджання / ПКМ для розряджання».
- Заряджання: один патрон за **16 тіків (0,8 с)**. Розряджання: один патрон за **10 тіків (0,5 с)**. Обмеження діють на клієнті й сервері.
- Усунення клину **одиночним натисканням R**: анімація триває після відпускання клавіші, збережено серверну перевірку.
- Серверна перевірка вибраних магазинів, цілісності інвентарю й стану зброї, заміна магазинів за одну операцію.
- Стандартні анімації використовуються тимчасово до готовності окремих анімацій магазинів.

## Для офіційного проєкту

Перенесено лише універсальні механіки. Оновлено `BulletEntity` і `LaserEffectRenderer` **лише** для універсальних слідів попадань та лазера. Публічна система `PlayerAnatomy` і `PlayerHitZoneConfig` збережена. Специфічні хітбокси AftermatchDayZ, міст ліхтарика та сторонні серверні інтеграції не додаються. Оригінальна гілка `forge-1.20.1-port` залишається недоторканою.

Назви Java-класів нейтральні, але історичні NBT-ключі `aftermatch_*` збережені для сумісності з уже створеними предметами. Звичайний інвентар Minecraft підтримується, кастомний інвентар Aftermatch не потрібен. Для гілки діє перевірка компіляції та створення тестового JAR у GitHub Actions; фінальна публікація потребує тестування.

Повний опис: `UPSTREAM-FEATURES.md`.

## Додатково перенесено 26 жовтня 2026

- Звичайна перезарядка вибирає **найповніший сумісний магазин**: спочатку серед магазинів останнього обраного вручну типу, інакше серед усіх сумісних. Однакова кількість набоїв — порядок інвентарю.
- Звуки завантаження одного патрона (два випадкові варіанти) і розряджання патрона (один варіант), лише після успішного серверного перенесення.
- Виправлено роботу прив'язок на середню та додаткові кнопки миші; зареєстровано перевірку патронника.
- Радіальне меню — темна графітова палітра із золотистими акцентами; без залежності від Luxium.
- Додатковий налаштовуваний пружний нахил зброї й рук під час стрільби від стегна, без змін ADS та балістики.
- Прицільна крапка від стегна збільшена приблизно на один видимий піксель.
- Новий рендер лазерної точки на поверхнях з окремою текстурою.
- Клієнтські сліди попадань куль на блоках: максимум 256, час існування до 90 секунд, повідомлення надсилає сервер гравцям поблизу.
- **Збережено публічну анатомічну систему PlayerAnatomy і PlayerHitZoneConfig** без інтеграції зі специфічними хітбоксами AftermatchDayZ.

**Перед публікацією:** протестувати всі функції в одиночному/мережевому Minecraft Forge 1.20.1; перевірити сумісність лазера із шейдерами та права на поширення трьох звукових файлів.
